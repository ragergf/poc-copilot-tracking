# Contributing to poc-copilot-tracking

Thank you for your interest in contributing! The following guidelines will help you get started.

## Reporting Bugs

If you encounter a bug, please [open an issue](../../issues/new) and include:

- A clear and descriptive title.
- Steps to reproduce the problem.
- What you expected to happen and what actually happened.
- Any relevant screenshots, logs, or error messages.

## Submitting Pull Requests

1. Fork the repository and create a new branch from `main`.
2. Make your changes with clear, focused commits.
3. Ensure your branch is up to date with `main` before opening a PR.
4. Open a pull request with a descriptive title and a summary of the changes.
5. Reference any related issues in the PR description (e.g., `Closes #1`).
6. Wait for a review; address any feedback before the PR is merged.

## Code Style Guidelines

- Keep changes small and focused on a single concern.
- Use clear, descriptive names for variables, functions, and files.
- Follow the conventions already present in the repository (indentation, formatting, etc.).
- Prefer YAML for workflow files and Markdown for documentation.
- Document any non-obvious logic with concise inline comments.
